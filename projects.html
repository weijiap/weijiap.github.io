  • ML Production API

    A production-ready machine learning inference service built with FastAPI, scikit-learn, Docker, and GitHub Actions CI. The project demonstrates how to move a trained model from a notebook to a tested, containerized REST API with structured logging, Pydantic request validation, environment-based configuration, and automated quality checks (Ruff, mypy, pytest).
