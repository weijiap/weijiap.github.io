AutoForecast Lab

Machine learning forecasting platform — from raw CSV to validated predictions, REST API, and interactive dashboard

View on GitHub →

An end-to-end time-series forecasting system that ingests raw data, engineers features automatically, trains and evaluates a machine learning model using walk-forward validation to prevent data leakage, and exposes results through both a FastAPI REST service and an interactive Streamlit dashboard — all containerized and covered by CI.

⚙️
ML Pipeline Automated lag, rolling, and calendar feature engineering. Chronological train/test splits with expanding-window walk-forward validation to eliminate look-ahead bias.
🖥️
Full-Stack System FastAPI REST service for programmatic access and a Streamlit dashboard for interactive exploration, CSV upload, and downloadable forecast results.
🔁
Production Engineering Docker containerization, GitHub Actions CI, Ruff linting, mypy static type checking, and pytest for reproducible and regression-safe builds.

Production Deployment

ML Production API

Containerized REST inference service — bridging the gap between a trained model and a deployable, monitored API

View on GitHub →

A production-ready template for serving trained machine learning models as a REST API. The project focuses on the engineering gap between a working notebook and a deployable service — covering model lifecycle management, typed request contracts, structured logging, environment-based configuration, and automated quality gates on every commit.

🚀
Inference Layer Model loaded once at startup via FastAPI lifespan to minimize per-request latency. Dedicated inference module keeps prediction logic decoupled from API routing.
🛡️
Typed Contracts Pydantic schemas validate every incoming request and enforce a consistent response structure. Environment variables drive config with no hard-coded deployment values.
✅
Quality Gates Ruff linting, mypy type checking, and pytest run automatically on every push via GitHub Actions CI, preventing formatting, typing, and functional regressions before merge.
