AutoForecast Lab

Time-series forecasting platform with REST API and interactive dashboard

An end-to-end forecasting system built on a modular pipeline: data ingestion and validation, feature engineering, model training with walk-forward evaluation, and forecast export — accessible through a FastAPI service and a Streamlit dashboard, containerized with Docker.

🖥️
API & Dashboard FastAPI service for programmatic access. Streamlit dashboard for CSV upload, interactive visualization, and downloadable results.

ML Production API

REST API for ML model serving, built around production engineering patterns

View on GitHub →

A FastAPI service organized around production engineering practices: typed request contracts, model lifecycle management, structured logging, environment-based configuration, and an OpenAPI endpoint. Packaged as a Docker image with automated CI checks on every push.

🚀
Inference Model loaded once at startup via FastAPI lifespan. Prediction logic isolated in a dedicated inference module, separate from routing and schemas.
🛡️
Contracts & Config Pydantic schemas for request and response validation. Application settings managed through environment variables.
✅
Tooling Ruff, mypy, and pytest run on every push via GitHub Actions CI.
